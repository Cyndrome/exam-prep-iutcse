Reach a Number

Start at 0. On move i you travel exactly i units, left or right. Find the minimum number of moves to end exactly on the target.

Step-by-step explanation

  1. Use symmetry. Reaching -t takes the same number of moves as reaching t (mirror every direction), so replace the target with its absolute value.
  2. Total reach after k moves. If every move goes right you end at S = 1 + 2 + … + k. You can never get farther than S, so we need S ≥ t.
  3. Flipping a move changes the result by an even number. Switching move i from right to left changes the final position by 2i. So the final position always has the same parity as S, and we need S - t to be even.
  4. Even is also enough. We must flip a set of moves whose lengths add up to (S - t) / 2. Every integer from 0 to S is a subset sum of {1..k}, so such a set always exists.
  5. Search. Increase k one at a time, keeping S as the running sum, until S ≥ t and (S - t) is even. That first k is the answer.
  6. Cost. For |t| ≤ 10⁹, k is about √(2·10⁹) ≈ 45 000, so a plain loop for each of ≤ 100 tests is instant. Use long long for the sum.

Worked trace on the samples

t = 2: k=1 → S=1 (<2); k=2 → S=3 (diff 1, odd); k=3 → S=6 (diff 4, even) → 3.
t = 3: k=1 → S=1; k=2 → S=3 (diff 0, even) → 2.
t = −2 → |t| = 2 → 3.

Code — reach_a_number.cpp

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        long long t;
        scanf("%lld", &t);
        if (t < 0) t = -t;
        long long k = 0, sum = 0;
        // smallest k with sum >= t and (sum - t) even
        while (sum < t || (sum - t) % 2 != 0) {
            k++;
            sum += k;
        }
        printf("%lld\n", k);
    }
    return 0;
}
Time O(√|t|) per test, memory O(1).

Last Moment Before All Ants Fall Out of a Plank

Ants walk at speed 1 on a plank of length L and reverse on meeting. Find when the last ant falls off.

Step-by-step explanation

  1. Key observation. When two identical ants meet and both reverse, the picture looks exactly the same as if they had walked through each other. Only the identities of the ants swap, and identities do not matter for the answer.
  2. So ignore collisions. Every ant effectively walks in a straight line until it leaves the plank.
  3. Fall time of one ant. A left-moving ant at position x needs x seconds to reach 0. A right-moving ant at position x needs L − x seconds to reach L.
  4. Answer. The last ant to fall corresponds to the maximum of all these individual times.
  5. Input handling. Read exactly p numbers for the left list, then exactly q for the right list. If a count is 0, nothing is read for it. scanf skips whitespace, so line breaks do not matter.

Worked trace on the samples

L=4, left ants at 4, 3 → times 4, 3. Right ants at 0, 1 → times 4−0=4, 4−1=3. Maximum = 4.
L=7, all eight ants move right, positions 0..7 → times 7..0 → 7.
L=7, all move left, positions 0..7 → times 0..7 → 7.

Code — ants_on_a_plank.cpp

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int L, p, q;
        scanf("%d %d %d", &L, &p, &q);
        int ans = 0;
        // Collisions are equivalent to ants passing through each other.
        for (int i = 0; i < p; i++) {
            int x;
            scanf("%d", &x);
            ans = max(ans, x);       // left-moving ant falls at time x
        }
        for (int i = 0; i < q; i++) {
            int x;
            scanf("%d", &x);
            ans = max(ans, L - x);   // right-moving ant falls at time L - x
        }
        printf("%d\n", ans);
    }
    return 0;
}
Time O(p + q) per test, memory O(1).
Lab 1Greedy / Two passesC++

Candy

Give each child at least one candy; a child with a higher rating than a neighbour must get strictly more candies than that neighbour. Minimise the total.

Step-by-step explanation

  1. Start everyone at 1 candy (c[i] = 1), which satisfies the first rule.
  2. Left-to-right pass. If r[i] > r[i−1], set c[i] = c[i−1] + 1. After this pass every child respects the rule against the left neighbour.
  3. Right-to-left pass. If r[i] > r[i+1], set c[i] = max(c[i], c[i+1] + 1). The max keeps the left-pass requirement while also satisfying the right neighbour.
  4. Why it is minimal. Each value is the smallest number that satisfies the constraints coming from one side, and the max combines the two sides. Nothing is ever given more than a constraint forces.
  5. Equal ratings impose no constraint, so they are left alone.
  6. Sum all values in a long long and print only the total.

Worked trace on the samples

Ratings 1 0 2: start [1,1,1]. Left pass: 0>1? no; 2>0 → c[2]=2 → [1,1,2]. Right pass: i=1: 0>2? no; i=0: 1>0 → c[0]=max(1,1+1)=2 → [2,1,2]. Total 5.
Ratings 1 2 2: left pass → [1,2,1]; right pass changes nothing → total 4.
Single child → 1.

Code — candy.cpp

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int n;
        scanf("%d", &n);
        vector<int> r(n), c(n, 1);
        for (int i = 0; i < n; i++) scanf("%d", &r[i]);
        for (int i = 1; i < n; i++)
            if (r[i] > r[i - 1]) c[i] = c[i - 1] + 1;
        for (int i = n - 2; i >= 0; i--)
            if (r[i] > r[i + 1]) c[i] = max(c[i], c[i + 1] + 1);
        long long total = 0;
        for (int i = 0; i < n; i++) total += c[i];
        printf("%lld\n", total);
    }
    return 0;
}
Time O(n), memory O(n).

Implement an Array-Based Stack

Build a LIFO stack on a plain array with push, pop, top, size, isEmpty, isFull and display, and drive it with a command list.

Step-by-step explanation

  1. Storage. A global long long stk[] array holds the values and an int topIdx counts the stored items, so it is also the index of the next free slot. capacity holds the case's N.
  2. Simple queries. isEmpty() is topIdx == 0, isFull() is topIdx == capacity, size() returns topIdx.
  3. Mutating functions return a status instead of printing. push(x) returns false if full, otherwise stores stk[topIdx++]. pop(v) and top(v) return false if empty and otherwise give the value through a reference. Not printing inside them is what lets the same code be reused in the Parentheses problem.
  4. display() prints from topIdx−1 down to 0, separated by single spaces. It is only called by main after a successful push.
  5. Command loop. For each case read N, set capacity = N and topIdx = 0 (empty stack), then read command words with scanf("%s") until END. Only PUSH reads an extra number.
  6. Output rules. After PUSH print the stack or Stack is full; POP prints the removed value or Stack is empty; TOP prints the top or Stack is empty; SIZE prints a number; EMPTY and FULL print YES/NO; END prints nothing.
  7. No STL. Only <cstdio> and <cstring> are included, and strings are plain char arrays.

Worked trace on the samples

N=3: PUSH 10 → 10; PUSH 20 → 20 10; TOP → 20; PUSH 30 → 30 20 10; FULL → YES; PUSH 40 → Stack is full; SIZE → 3; POP → 30; POP → 20; EMPTY → NO; POP → 10; POP → Stack is empty; TOP → Stack is empty; EMPTY → YES.

Code — array_stack.cpp

// Implement an Array-Based Stack (no STL)
#include <cstdio>
#include <cstring>

const int MAXCAP = 200005;

long long stk[MAXCAP];  // storage
int topIdx = 0;         // number of stored items (next free slot)
int capacity = 0;       // capacity N of the current case

bool isEmpty() { return topIdx == 0; }
bool isFull()  { return topIdx == capacity; }
int  size()    { return topIdx; }

// Returns false (and leaves the stack unchanged) if full.
bool push(long long x) {
    if (isFull()) return false;
    stk[topIdx++] = x;
    return true;
}

// Returns false (and leaves the stack unchanged) if empty.
bool pop(long long &removed) {
    if (isEmpty()) return false;
    removed = stk[--topIdx];
    return true;
}

// Returns false if empty.
bool top(long long &value) {
    if (isEmpty()) return false;
    value = stk[topIdx - 1];
    return true;
}

// Prints stored values from top to bottom, separated by one space.
void display() {
    for (int i = topIdx - 1; i >= 0; i--) {
        printf("%lld", stk[i]);
        if (i > 0) printf(" ");
    }
    printf("\n");
}

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        int N;
        if (scanf("%d", &N) != 1) return 0;
        capacity = N;
        topIdx = 0;  // stack starts empty for every case

        char cmd[16];
        while (scanf("%15s", cmd) == 1) {
            if (strcmp(cmd, "END") == 0) break;
            if (strcmp(cmd, "PUSH") == 0) {
                long long x;
                scanf("%lld", &x);
                if (push(x)) display();
                else printf("Stack is full\n");
            } else if (strcmp(cmd, "POP") == 0) {
                long long v;
                if (pop(v)) printf("%lld\n", v);
                else printf("Stack is empty\n");
            } else if (strcmp(cmd, "TOP") == 0) {
                long long v;
                if (top(v)) printf("%lld\n", v);
                else printf("Stack is empty\n");
            } else if (strcmp(cmd, "SIZE") == 0) {
                printf("%d\n", size());
            } else if (strcmp(cmd, "EMPTY") == 0) {
                printf(isEmpty() ? "YES\n" : "NO\n");
            } else if (strcmp(cmd, "FULL") == 0) {
                printf(isFull() ? "YES\n" : "NO\n");
            }
        }
    }
    return 0;
}
Every operation is O(1); memory O(capacity).

Parentheses Balance

Decide whether a string made of ( ) [ ] is a correctly nested bracket sequence, using the stack from the previous task.

Step-by-step explanation

  1. Reuse the stack. The same array-based functions are pasted in, with the capacity raised to 200 005 so even a very long string cannot overflow it. Nothing in the stack prints in this task.
  2. Scan left to right. For an opening bracket ( or [, push it.
  3. For a closing bracket, the most recent unclosed opener must be the matching type. Look at the top: if the stack is empty, or the top is the wrong kind, the string is wrong, so answer No immediately. Otherwise pop it.
  4. At the end the stack must be empty. Leftover openers mean something was never closed.
  5. Why checking the type matters. ([)] has a partner for every bracket but is still invalid, because ] would close while ( is still open inside it. A stack catches this because only the top can be closed.
  6. Input handling. Read each string with a char buffer (up to 100 000 characters), reset the stack for every string, and print Yes or No per line.

Worked trace on the samples

(([()]))): push ( ; push ( ; push [ ; push ( ; ) pops ( ; ] pops [ ; ) pops ( ; ) pops ( ; the stack is now empty; the final ) finds no top → No.
([]): push ( ; push [ ; ] pops [ ; ) pops ( ; empty at the end → Yes.

Code — parentheses_balance.cpp

// Parentheses Balance (no STL) - reuses the array-based stack from Task B
#include <cstdio>
#include <cstring>

const int MAXCAP = 200005;

long long stk[MAXCAP];
int topIdx = 0;
int capacity = 0;

bool isEmpty() { return topIdx == 0; }
bool isFull()  { return topIdx == capacity; }
int  size()    { return topIdx; }

bool push(long long x) {
    if (isFull()) return false;
    stk[topIdx++] = x;
    return true;
}

bool pop(long long &removed) {
    if (isEmpty()) return false;
    removed = stk[--topIdx];
    return true;
}

bool top(long long &value) {
    if (isEmpty()) return false;
    value = stk[topIdx - 1];
    return true;
}

// Kept from Task B for completeness; not called in this task
// (stack operations must not print anything here).
void display() {
    for (int i = topIdx - 1; i >= 0; i--) {
        printf("%lld", stk[i]);
        if (i > 0) printf(" ");
    }
    printf("\n");
}

static char s[100010];

bool isCorrect(const char *str) {
    topIdx = 0;
    capacity = MAXCAP;  // capacity increased as needed
    for (int i = 0; str[i]; i++) {
        char c = str[i];
        if (c == '(' || c == '[') {
            push(c);
        } else if (c == ')' || c == ']') {
            long long t;
            if (!top(t)) return false;
            char want = (c == ')') ? '(' : '[';
            if (t != want) return false;
            pop(t);
        }
    }
    return isEmpty();
}

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    while (T--) {
        scanf("%100005s", s);
        printf(isCorrect(s) ? "Yes\n" : "No\n");
    }
    return 0;
}
Time O(length) per string, memory O(length).

Asteroid Collision

Asteroids move at the same speed; positive means right, negative means left. Smaller ones explode on collision, equal sizes both explode. Output the survivors in order.

Step-by-step explanation

  1. When can a collision happen? Only when a right-moving asteroid (positive) is somewhere to the left of a left-moving one (negative). Two asteroids going the same way never meet, and a left-mover followed by a right-mover move apart.
  2. Keep a stack of survivors (a vector<int> used as a stack). Process the asteroids left to right.
  3. For each new asteroid a, if it is positive, or the stack is empty, or the top is negative, it cannot collide, so push it.
  4. If a is negative and the top is positive, they collide: if the top is smaller (top < -a), pop it and keep fighting with the next top; if equal, pop it and a also dies; if the top is bigger, a dies and the top stays.
  5. If a survives all those fights, push it.
  6. Each asteroid is pushed once and popped at most once, so the whole case is O(n).
  7. Output. Print the stack from bottom to top, separated by spaces, or Empty if nothing is left.

Worked trace on the samples

5 10 -5: push 5; push 10; −5 meets 10, and 10 is bigger so −5 dies → 5 10.
8 -8: push 8; −8 equals 8, both vanish → Empty.
10 2 -5: push 10; push 2; −5 beats 2 (pop), then meets 10 and dies → 10.

Code — asteroid_collision.cpp

// Asteroid Collision - stack, O(n) per test case (STL allowed)
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int n;
        scanf("%d", &n);
        vector<int> st;
        for (int i = 0; i < n; i++) {
            int a;
            scanf("%d", &a);
            bool alive = true;
            while (alive && a < 0 && !st.empty() && st.back() > 0) {
                if (st.back() < -a) {
                    st.pop_back();          // right-moving one explodes
                } else if (st.back() == -a) {
                    st.pop_back();          // both explode
                    alive = false;
                } else {
                    alive = false;          // current one explodes
                }
            }
            if (alive) st.push_back(a);
        }
        if (st.empty()) {
            printf("Empty\n");
        } else {
            for (size_t i = 0; i < st.size(); i++) {
                if (i) printf(" ");
                printf("%d", st[i]);
            }
            printf("\n");
        }
    }
    return 0;
}
Time O(n) per case, memory O(n).
